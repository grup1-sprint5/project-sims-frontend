# Documentació completa de la app (SIMS Frontend)

Aquesta carpeta recull una visió completa de l'aplicació en diversos nivells: funcional, tècnic i conceptual.

## Índex

- `docs/01-visio-general.md` — Què és la plataforma, perfils d'usuari i capacitats principals.
- `docs/02-funcionalitats.md` — Funcionalitats per mòdul (client, admin, suport, landing).
- `docs/03-arquitectura-tecnica.md` — Stack, arquitectura frontend, rutes, estat, i18n i UI.
- `docs/04-autenticacio-i-tenancy.md` — Fluxos d'autenticació, cookies, `X-Tenant`, domini central i subdominis.
- `docs/05-fluxos-de-dades.md` — Com circula la informació en reserves, mapa, tiquets i perfil.
- `docs/06-assistent-ia-i-memoria.md` — Funcionament de l'assistent i què vol dir “memòria” al sistema actual.

## Lectura recomanada

1. Comença per `01-visio-general.md`.
2. Continua per `02-funcionalitats.md`.
3. Si has de tocar codi, passa a `03-*`, `04-*` i `05-*`.
4. Per entendre el xat/IA, llegeix `06-assistent-ia-i-memoria.md`.
